## 5. Inventory app + cloud sync (LIVE, 2026-09-16)
- Source: `Rally Inventory/rally_lighting_inventory.html` (single-file app; JSON export/import,
  CSV export). Deployed as `public/inventory/index.html`, served at `/inventory` via a
  `beforeFiles` rewrite; gated by `src/middleware.ts` Basic Auth (`INVENTORY_USER/PASSWORD`
  → falls back to `DASHBOARD_USER/PASSWORD`). `robots` disallows it; no-store/noindex headers.
- **Login:** the old dashboard credentials were stored as *sensitive* in Vercel (unrecoverable),
  so they were rotated on 2026-09-16 (`vercel env rm/add` + empty-commit redeploy). The new
  value was given to Jason in chat and is NOT written anywhere else. If lost again: repeat the
  rotation (2 minutes). Same login serves `/dashboard` and `/inventory`.
- **Cloud sync:** `/inventory/api` (GET/PUT, same auth gate) → private Vercel Blob store
  **rally-inventory** (`store_rDxIQipeqdQct3CO`, `BLOB_READ_WRITE_TOKEN` in all envs).
  Immutable versions `inventory/state-<updatedAt>.json`, newest via `list()`, 409 guard against
  stale overwrites, 10 versions kept. App: `save()` → localStorage + debounced PUT; pulls on
  boot/focus/45s/online; `#sync-pill` status; first-sync prompt when both copies have data.
  Lessons: don't overwrite a single blob path (stale/404 reads right after overwrite); the SDK's
  `get()` returns null inside Next route handlers → content is fetched directly with the RW token
  + `cache: "no-store"`. Test with `INVENTORY_BLOB_PREFIX=inventory-test/` so `inventory/` stays clean.
- To update the app: edit the source file, copy to `public/inventory/index.html`, push `main`.
